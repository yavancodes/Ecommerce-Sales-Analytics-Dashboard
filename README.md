# 🛒 E-Commerce Sales Analytics

**End-to-End Data Analytics Project using Python, MySQL, Excel & Data Visualization**

## 📌 Project Overview

This project focuses on analyzing 120 sample e-commerce orders to understand sales performance, product trends, customer locations, and payment preferences.

The objective is to transform raw sales data into meaningful business insights using Python, MySQL, and Excel.

This project demonstrates a beginner-friendly end-to-end data analytics workflow, including data exploration, SQL analysis, business problem-solving, and data visualization.

## 🎯 Project Objectives

- Analyze overall sales and order performance.
- Identify top-performing products and categories.
- Understand monthly sales trends.
- Analyze city-wise sales performance.
- Explore customer payment preferences.
- Understand order status distribution.
- Create visual reports to communicate business insights.

## 📊 Dataset Information

The dataset contains 120 generated sample e-commerce orders.

### Dataset Columns

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Order_Date | Date of order |
| Customer_ID | Customer identifier |
| City | Customer city |
| Product | Product name |
| Category | Product category |
| Quantity | Number of items ordered |
| Unit_Price | Price per item |
| Discount_Percent | Discount percentage |
| Sales | Final sales amount |
| Payment_Method | Payment method |
| Order_Status | Order status |

### Sales Calculation

Sales amount is calculated after applying the discount:

`Sales = Quantity × Unit_Price × (1 - Discount_Percent / 100)`

## 🐍 Python Analysis

Python is used for:

### How to Run Python Project

**Step 1:** Install Python.

**Step 2:** Download or clone this repository.

**Step 3:** Open the project folder in VS Code.

**Step 4:** Open the terminal and install the required libraries.

```bash
pip install -r requirements.txt
```

**Step 5:** Run the Python file.

```bash
python ecommerce_sales_analysis.py
```

The script prints summary information and generates six charts.
